## 0.1.0（2026-11-13 首次交付，持续迭代至 2026-11-17）

> 本版本于 2026-11-13 17:27 首次交付。到 0.2.0 之前，所有功能、交互、部署和文档更新都没有提升版本号，仍以 0.1.0 发布；以下按日期归档。当前 `release\LanFilePlatform-0.1.0.zip` 是该阶段最后一次构建，可用于回退。

### 2026-11-13：立项、首版交付与部署修复

- 确定方案：Windows 专用主机 + Go 后台服务 + React/Ant Design 中文网页 + SQLite（WAL）；浏览器访问，不安装客户端，不使用 Docker、Python 或外部数据库。
- 需求边界：全员共享命名空间；管理员、编辑者、只读者三类角色；管理员建号，首次登录强制改密；不做自动同步、在线编辑和细粒度目录权限。
- 首版功能：账号与权限、目录树与面包屑、多文件/拖拽上传与队列、流式写盘、历史版本、版本冲突保护、回收站、操作日志与 CSV 导出、独立备份与恢复、自动 HTTPS 证书、Windows 服务安装/卸载/防火墙脚本。
- 自动化测试覆盖首次初始化、上传与历史版本、冲突拒绝、恢复、权限、回收站、并发更新、审计导出、文件夹 ZIP 下载、备份恢复和路径安全。
- 修复 Go 路由注册冲突、上传事务外键顺序、服务模式日志为空等问题。
- 修复含空格安装路径下 `sc.exe create` 丢失引号的问题，改用 PowerShell `New-Service` 注册后再设置 LocalService 账号。
- 构建脚本固定使用国内 Go 模块代理 `goproxy.cn`，避免 `proxy.golang.org` 不可达导致重建失败。
- `8443` 在办公主机上已被其他程序占用（浏览器出现对方的 HTTP Basic 认证弹窗）。正式默认端口统一改为 `9443`，程序默认值、安装/卸载/证书脚本、页面提示和全部文档同步更新。
- 备份新增 `files\` 可读副本：按原目录和文件名保存当前版本，可直接在资源管理器打开；历史版本仍保存在 `objects\` 和 `meta.db`。Windows 保留名（如 `CON.txt`）自动改成 `_CON.txt`。
- 文件浏览交互：双击文件夹进入；文件夹“⋮”菜单支持整目录 ZIP 下载；每行右侧新增独立下载按钮，文件和文件夹都可直接下载。
- HTTPS 证书改为“本地根证书 + 服务器证书”：根证书 10 年，服务器证书 2 年；主机 IP/名称变化时自动重签服务器证书，员工电脑无需重新导入；根证书剩余不足 1 年时重建。
- 修复 Windows PowerShell 5.1 设置证书回调后所有 HTTPS 请求中断的问题：证书信任脚本改用系统 `curl.exe` 下载，并新增 `/api/server-cert` 核对 SAN。
- 新增「一键信任证书.cmd」，支持当前用户或所有用户导入，并做证书链验证。
- 密码最小长度从 8 位调整为 6 位，前后端和文档同步。
- 文档中的局域网访问地址统一为 `https://192.168.1.100:9443/`。

## 0.2.1（2026-11-17）目录树展开状态修复

### 修复

- 首次进入文件界面时，左侧目录树全部收起，不再默认全展开。
- 切到管理后台再返回文件界面时，恢复最后一次的展开/收起状态，不再自动展开或收起。
- 手动折叠父目录后切换界面，保持折叠状态。
- 从主界面进入深层文件夹时，仍会自动展开祖先目录以显示选中项；返回上一级不会收起。
- 刷新页面后恢复为全部收起。

### 原因与处理

- Ant Design 在折叠父目录时会保留子目录的展开 key，重新挂载时被当成“有展开子项”而把父级撑开。修复方式是在每次更新时清理不可见的子项 key，并关闭 `autoExpandParent`。

### 验证

- 用多级目录实测 6 个场景：首次进入、后台往返、手动折叠后往返、主区域进入子目录、返回上一级、刷新页面，全部符合预期。
