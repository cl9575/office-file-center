# 员工使用说明

办公室文件中心用于把办公文件集中保存在主机上，并保留每一次更新。它类似内部网盘，不是自动同步盘：**在电脑上修改文件后，需要回到网页上传新版本**。

## 1. 第一次使用

1. 双击管理员发来的 `一键信任证书.cmd`，等待窗口显示“证书链验证：通过”后按任意键关闭。若希望这台电脑的所有 Windows 用户都信任，右键该文件选择“以管理员身份运行”。也可以用管理员发来的 `.cer` 文件手动导入。
2. 使用 Edge 或 Chrome 打开管理员提供的地址。**地址必须填写主机的局域网 IP**（当前办公环境为 `192.168.1.100`，以实际为准），例如：
   `https://192.168.1.100:9443`
   不要填写 `localhost` 或 `127.0.0.1`，否则打开的是员工自己的电脑。
3. 输入管理员分配的账号和初始密码。
4. 第一次登录会要求修改密码。设置至少 6 位的新密码后进入文件中心。

如果浏览器提示“证书不受信任”，请先完成第 1 步，不要直接忽略警告。证书只需信任一次。导入证书后要完全退出并重新打开浏览器（可在地址栏访问 `edge://restart` 或 `chrome://restart`），仅刷新页面可能仍显示旧警告。 如果双击时 Windows 提示“已保护你的电脑”，点击“更多信息 → 仍要运行”。

## 2. 界面

- 左侧：文件目录树，可展开文件夹；“全部项目”固定显示在最上方，不能收起。直接位于“全部项目”下的文件夹即项目，图标和文字会加粗区分。“全部项目”右侧的“+”可直接新建项目（编辑者和管理员可见）。
- 顶部：搜索框、管理后台入口（仅管理员）、个人菜单（修改密码、退出登录）。
- 中间：当前目录的文件和文件夹。
- 每行右侧的下载图标：文件直接下载，文件夹打包为 ZIP 下载。
- 文件右侧的“⋮”：下载、历史版本、重命名、移动到、移入回收站等操作。
- 在文件行或目录树节点上右键，会显示相同的操作菜单；在文件区域空白处右键可新建项目/文件夹、上传文件或刷新。顶部栏等页面其他区域仍保留浏览器原生右键。
- 文件列表不支持拖动选中文字；需要复制名称时，在文件或文件夹行上右键选择“复制文件名”。
- 右上角：上传文件、新建项目/文件夹、刷新。在“全部项目”下按钮显示为“新建项目”，进入项目后显示为“新建文件夹”。

窄屏或窗口较小时，左侧目录会收起，仍可通过顶部面包屑和点击文件夹前进/返回。

## 3. 浏览和搜索

- 双击文件夹行（或文件夹名称）进入，点击顶部面包屑返回上级；双击文件行打开文件详情。
- 进入文件夹后，面包屑左侧会出现“返回上一级”按钮，可回到上级文件夹；位于“全部项目”根目录时该按钮不显示。
- 从主区域进入子文件夹时，左侧目录树会自动展开到当前目录并高亮选中；返回上级或点击面包屑切换目录时，已展开的目录不会自动收起。
- 单击左侧目录树中的项目或文件夹即可进入；再次单击已选中的文件夹会展开/收起其子目录（等同点击左侧箭头），不会跳回根目录。返回根目录请点击最上方的“全部项目”。
- 在顶部搜索框输入文件或文件夹名称，按回车查看结果；结果会显示所在位置。
- 搜索只匹配名称，不搜索文件正文。清空搜索框可返回目录浏览。

## 4. 上传文件和文件夹

### 上传新文件

1. 进入目标文件夹。
2. 点击“上传文件”，选择一个或多个文件；也可以直接把文件拖进页面。
3. 底部“上传队列”显示进度，可同时上传两个文件，其余等待。

上传成功后文件列表会刷新。

### 上传整个文件夹

1. 进入目标文件夹，点击“上传文件夹”，选择本地文件夹；也可以直接把这个文件夹拖进页面。
2. 系统会在当前位置按原名称创建同名文件夹，并保留内部子目录结构；如果同名文件夹已存在，会直接合并进去，不会重复创建。
3. 同名文件自动覆盖为新版本（原内容保留在该文件的历史版本中），不会逐个弹窗询问。
4. 空文件夹不会上传；超过大小上限、名称不合法，或与现有文件夹/文件类型冲突的项目会跳过，并在提示中给出跳过数量。

### 上传修改后的新版本

1. 在目标文件夹点击“上传文件”，选择修改后的文件。
2. 如果同名文件已存在，会弹出“发现同名文件”：
   - **替换为新版本**：保留原历史，把新内容保存为 V2、V3……这是日常更新文件的方式。
   - **使用新名称上传**：修改下面的名称，作为另一个文件保存。
   - **跳过该文件**：放弃这次上传。
3. 建议在更新前先打开文件的“历史版本”确认当前版本和最后更新人，避免覆盖同事的新修改。

系统会提示当前版本、上传人和更新时间。若你上传时别人刚刚更新过，系统会拒绝并提示“文件已被他人更新”，此时刷新后再重新上传，不要强行改名绕过。

### 队列操作

- 上传中可以点“取消”。
- 批量上传时，顶部只在整批结束后提示一次结果；每个文件的进度和失败原因在“上传队列”中查看。
- 网络失败、服务器临时错误可点“重试”。
- 文件超过管理员设置的大小上限时，会直接提示；请联系管理员调整或压缩文件。
- 当前版本不支持断点续传，网络中断后需要重新上传该文件。

## 5. 下载和历史版本

- 点击行右侧下载图标，或“⋮ → 下载当前版本”。
- 下载文件夹时点击行右侧下载图标，或“⋮ → 下载文件夹（ZIP）”；压缩包会保留原文件夹层级和当前版本文件。
- 在“文件详情”中可查看大小、SHA-256、更新人和更新时间。
- 打开“历史版本”：
  - 每个版本有版本号、上传人、时间和大小；
  - 可以下载任意历史版本；
  - 编辑者和管理员可以把某个历史版本“恢复”为新的当前版本（例如误覆盖后找回内容）。
- “操作记录”显示这个文件的上传、更新、改名、移动、下载等记录。

恢复历史版本不会删除之后的记录，而是生成一个新的版本号。

## 6. 新建项目/文件夹、重命名和移动

- 在“全部项目”下点击“新建项目”创建一级项目（即根目录下的文件夹）；进入项目后可继续“新建文件夹”。
- 右侧“⋮ → 重命名”修改名称。
- “移动到…”选择目标文件夹。不能把文件夹移动到自己的子目录。
- 已经存在的历史版本会随文件一起移动，不会丢失。

## 7. 删除和恢复

- 删除文件或文件夹会先进入**回收站**，不会立即永久消失。
- 文件夹删除会连同里面的内容一起进入回收站。
- 普通用户看不到回收站；需要恢复时联系管理员。
- 管理员可在“管理后台 → 回收站”恢复。若原位置已有同名项目，恢复会被拒绝，需要先处理同名文件。
- 永久删除不可撤销，请管理员在确认无用时再操作。回收站也可“清空回收站”一键全部永久删除。

## 8. 常见提示

| 提示 | 含义和处理 |
|---|---|
| 用户名或密码错误 | 检查大小写；连续失败 5 次会被临时限制，约 5 分钟后再试 |
| 登录已过期 | 重新登录 |
| 请先修改密码 | 使用管理员给的初始密码登录后，先设置新密码 |
| 文件超过大小限制 | 联系管理员，或压缩/拆分文件 |
| 同名项目已存在 | 在弹窗中选择替换为新版本或改名 |
| 文件已被他人更新 | 刷新页面查看最新版本，再重新上传 |
| 服务器磁盘空间不足 | 联系管理员清理空间；不要重复上传 |
| 只有管理员可以恢复回收站 | 联系管理员处理 |

## 9. 账号安全

- 不把账号借给他人；共用电脑用完请退出登录。
- 密码至少 6 位，建议使用短语并定期更换。
- “个人菜单 → 修改密码”可自行修改。
- 忘记密码请联系管理员重置，重置后首次登录需要再改密码。

## 10. 重要习惯

- **平台不是自动同步盘**：本地修改后要上传新版本。
- 不要把文件只存在自己的电脑上；重要资料应上传到平台。
- 需要找回旧内容时，先查看历史版本，不要直接覆盖上传。
- 平台的历史版本在同一台主机上，管理员会另行做独立备份；如遇主机故障，请联系管理员恢复。
